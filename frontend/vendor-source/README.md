# Исходники сторонних компонентов (промежуточное хранение)

Здесь лежат исходники React Bits-компонентов в том виде, в котором они были
получены: JavaScript + отдельный CSS-файл.

**Эта папка не участвует в сборке.** Она вне `src/`, поэтому ни Next, ни
TypeScript её не компилируют. Файлы хранятся как эталон до переноса.

## Что предстоит сделать при переносе

Каждый компонент нужно перенести в `src/components/vendor/` с изменениями:

1. **Перевести на TypeScript** — типизировать пропсы, убрать неявные `any`.
2. **Заменить хардкод цветов на токены темы** — компоненты написаны под свою
   палитру и в текущем виде проигнорируют светлую тему.
3. **Добавить директиву `"use client"`** — все пять используют DOM API.
4. **Уважать `prefers-reduced-motion`** — ни один из них этого не делает.
5. **Отключать работу вне вьюпорта** — у `Ferrofluid` для этого есть проп
   `paused`, остальным нужен `IntersectionObserver`, иначе анимация будет жечь
   кадры на невидимых элементах.
6. **Перенести CSS** в общую систему или оставить рядом как CSS-модуль.

## Состав

| Компонент | Зависимость | Где планируется применить |
|---|---|---|
| `Ferrofluid` | `ogl` (WebGL) | Фон hero на главном экране, один раз, лениво |
| `SpecularButton` | `ogl` (WebGL) | Единственная главная кнопка действия на экране |
| `CurvedInput` | — | Центральное поле AI-запроса на главном экране |
| `AnimatedList` | `motion` | Живая лента находок при поиске, поток событий |
| `MagicBento` | `gsap` | Сетка быстрых сценариев и метрик на главном экране |

Файлы `*.usage.jsx` — примеры вызова из документации, справочные.
